# 阶段 5 DMG 隔离验收

本流程仅适用于内部 macOS DMG artifact 和本地构建，不创建 Release、tag 或公开下载资产。

1. 记录候选 DMG 的绝对路径、SHA-256 与 `hdiutil verify` 结果，并确认当前运行 App 的实际路径。
2. 关闭同一 bundle identifier 的冲突实例；不要用 Finder 双击或旧的 `/Applications` 版本作为验收证据。
3. 使用 `scripts/run-stage5-isolated-dmg.sh` 直接运行挂载卷内的 `Contents/MacOS/yifumusic`。启动器会创建唯一临时根，设置 `HOME` 与受限的 `YIFUMUSIC_CONFIG_ROOT`，并在 UI 验收前验证临时 `config.toml` 与 SQLite 数据库；退出后还会比较真实配置根的递归文件快照，任何新增、删除或内容/元数据变化都使验收失败。
4. 在该隔离环境中确认 About 的版本、构建提交、构建时间、构建渠道/目标和当前语言代码。
5. 验证首次启动为简体中文；依次改为 English、重启、改回简体中文并重启，确认设置分类、音乐库、音频、界面、关于、主题与语言均正确显示。
6. 仅使用可公开用于验收的本地音乐目录完成扫描、播放、队列、歌词和桌面歌词冒烟验证。确认歌单与队列在扫描失败、缺失文件或 M3U 导入失败后仍可用。
7. macOS 的关闭主窗口会隐藏应用以保持播放，不等于退出候选进程。验收结束必须使用应用菜单“退出”或显式结束候选进程，随后等待启动器输出真实配置快照比较结果并卸载 DMG。仅在单独确认安装后，才复制 App 到 `/Applications`。

不得删除、打印、提交或上传真实用户的配置目录、数据库、音乐文件或凭据。隔离 HOME 仅用于本次验收，不能覆盖真实用户配置。
