# YifuMusic 南宫羽·以太紫 × 液态玻璃设计系统

## 产品定位

YifuMusic 是本地优先的桌面音乐工具。首屏始终是可操作的音乐界面，视觉层服务于扫描曲库、播放、队列、歌词和设置，不使用营销页、 oversized hero、装饰性悬浮卡片、渐变光球或遮挡播放操作的素材。

本系统使用 React、TypeScript、StyleX、TanStack Router、Tauri 与 Rust。页面结构优先保持真实本地工作流的可达性，视觉表面通过语义令牌统一，不在页面内重复定义主题色。

## 以太紫色板

| 令牌                 | 值                             | 用途                                          |
| -------------------- | ------------------------------ | --------------------------------------------- |
| `--main-color`       | `#7C5CFF`                      | 选中、按钮、进度、播放指示、焦点环            |
| `--main-color-light` | `#9D8CFF`                      | hover 高光、强调填充                          |
| `--main-color-deep`  | `#5B3FD4`                      | 按下态和深色强调表面                          |
| `--accent-pink`      | `#F472B6`                      | 播放中和偶像元素的小面积点缀，整体占比低于 8% |
| `--surface-canvas`   | 深色 `#0B0E16`，浅色 `#F5F6FF` | 页面画布                                      |
| `--surface-raised`   | 深色 `#161522`，浅色 `#FFFFFF` | 纯色抬升表面和玻璃降级表面                    |
| `--surface-sunken`   | 深色 `#10131C`，浅色 `#ECEBFA` | 输入、列表、凹陷区域                          |
| `--surface-hover`    | 深色 `#252033`，浅色 `#E5E2FF` | hover 与轻量反馈                              |

主色紫、灰阶和粉色点缀遵循 70% / 22% / 8% 的比例纪律。粉色不用于整块背景或主要导航选中态。`--main-color` 在深浅主题中保持 `#7C5CFF`，用户自定义强调色只通过既有 `ui_accent_color` 覆盖语义主色。

## 液态玻璃

玻璃表面使用半透明背景、边框高光和背景模糊。导航与标题栏使用 `blur(16px)`；播放器、队列和沉浸页的队列/歌词设置面板使用 `blur(24px) saturate(1.4)` 或对应的轻量变体。玻璃表面下的内容必须保持足够的文字对比度，不能用模糊制造信息层级。

| 语义                             | 开启时                      | 关闭时                  |
| -------------------------------- | --------------------------- | ----------------------- |
| `--glass-surface`                | 主题对应的半透明白色表面    | `var(--surface-raised)` |
| `--glass-backdrop-filter-soft`   | `blur(16px) saturate(1.15)` | `none`                  |
| `--glass-backdrop-filter-strong` | `blur(24px) saturate(1.4)`  | `none`                  |
| `--glass-highlight`              | 1px 内描边和微弱折射高光    | 不显示额外光晕          |

“液态玻璃效果”默认开启，配置键为 `liquid_glass`。关闭时通过应用壳条件属性和全局语义规则降级为纯色，保持尺寸、滚动、焦点顺序和交互路径不变。

## 动态效果

“动态效果”默认开启，配置键为 `dynamic_effects`。允许的反馈包括短时页面进入、播放中指示、进度和音量反馈、按钮 hover 位移与玻璃高光。关闭时禁用霓虹光晕、播放指示动画、位移动画以及过渡时长，不改变控件尺寸或可达性。

`prefers-reduced-motion: reduce` 始终优先：停止非必要动画、缩短过渡并使用即时滚动。用户主动关闭动态效果时，规则比系统偏好更严格，所有应用内动画和过渡都清零。

## 布局基线

应用壳由固定标题栏、可切换顶部/侧栏导航、中央滚动内容、固定播放器和独立队列组成。内容不嵌套在装饰性卡片中；卡片只用于重复设置项、列表项和确实需要框定的工具。

| 宽度     | 约束                                                               |
| -------- | ------------------------------------------------------------------ |
| `1440px` | 完整侧栏、内容最大宽度约 `1200px`、队列可作为右下辅助面板打开      |
| `1024px` | 侧栏可折叠、队列改为可关闭弹层、播放器核心控制保持可见             |
| `700px`  | 紧凑导航、标题和长文本可换行或省略、队列/设置分类/播放器操作仍可达 |

列表和网格使用稳定的列轨道、固定图标按钮尺寸和 `min-width: 0`。曲目标题、歌手、专辑和歌单名在容器内使用省略或自然换行，绝不覆盖相邻控件。播放器、队列、沉浸播放和桌面歌词保持独立入口，不改变 `src/lib/player.ts` 的唯一音频控制边界。

## 语义令牌

组件使用以下语义令牌，不直接绑定主题专属颜色：

- 画布与表面：`--surface-canvas`、`--surface-raised`、`--surface-sunken`、`--surface-hover`、`--surface-selected`。
- 文本与边框：`--text-primary`、`--text-secondary`、`--text-muted`、`--border-subtle`、`--border-strong`。
- 强调与表单：`--main-color`、`--accent`、`--accent-subtle`、`--accent-border`、`--accent-contrast`、`--focus-color`。
- 玻璃与动效：`--glass-surface`、`--glass-surface-solid`、`--glass-backdrop-filter-soft`、`--glass-backdrop-filter-strong`、`--glass-highlight`。
- 结构：`--radius-sm`、`--radius-md`、`--shadow-panel`、`--header-shadow`、`--font-mono`。

圆角以 `6px` 小圆角和 `8px` 中圆角为主；重复内容卡片不超过 `8px`，设置卡片沿用现有信息层级。阴影只表达悬浮层级，不用大面积光晕装饰。

## 状态和无障碍

- `hover`：轻微表面变化和可选短时位移，不能只改变颜色。
- `focus-visible`：使用 `2px` `--focus-color` 焦点环，焦点环在浅色和深色画布上都保持清晰。
- `selected` / 当前路由：同时使用背景、字重、图标或边框表达，不只依赖颜色。
- `disabled`：保持可读的中文原因、`aria-disabled` 或原生 `disabled`，降低对比度但不隐藏状态。
- `loading`：使用稳定尺寸的骨架或状态文案，不因加载文本改变布局。
- `empty` / `error`：说明真实本地数据状态和下一步，不显示虚构曲目或服务结果。
- 菜单、tooltip、dialog、队列和设置分类使用原生键盘路径；Tab、Shift+Tab、Escape 后焦点进入和恢复到触发控件。
- 默认语言为 `zh-CN`。新按钮、标题、空状态、错误、tooltip 和 `aria-label` 进入 Lingui，并遵循中文优先的自然表达。

## 资产边界

内置 UI 视觉只依赖本地代码和已登记素材。南宫羽仅作为以太紫色板和本阶段发现页指定视觉素材的来源提示；发现页角色图使用 `src/assets/moekoe/nangong-yu-cinema.webp`，由 `discover_character_visible` 控制，默认显示、可随时关闭，使用范围限于发现页分类区域。该素材不能自动扩展为沉浸场景、在线内容、品牌宣传或用户场景资产。

未来用户导入资产必须独立记录来源、权限、尺寸、生命周期和删除行为。不能新增未登记的角色、品牌、远程媒体或网络服务，也不能把角色素材当作播放结果或在线数据。
